programdemos/welcome/welcome.xtl

Welcome: one small calculation on which a newcomer is shown how these lessons work (the page steps through it, pictures it, writes one of its sums out). It is the layer of the first lesson, LoRA hello: a frozen table W of 4 rows and 4 columns with an adapter of rank 1, written this time as a pipeline: the input x, then the squeeze h = A x, then the spread u = B h, then the output y = W x + s u. X_eTaL-ML's Flow runs the pipeline and can report every stage's value, which is what a page steps through.
