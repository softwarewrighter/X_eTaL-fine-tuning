what is MoE2-LoRA?

MoE 
2
 -LoRA ("When MoE Models Meet MoE-style Low-Rank Adaptation", 2026) is a parameter-efficient fine-tuning (PEFT) method designed specifically for Mixture-of-Experts (MoE) large language models.

The "
MoE 
2
 " name comes from coupling two distinct MoE mechanisms together: the pretrained MoE backbone and an MoE-style pool of LoRA adapters. Rather than treating adapter routing and base-model routing separately, it binds them so the adapters leverage the routing intelligence the base model has already learned.

Core Problem It Solves
Prior approaches to fine-tuning MoE models fall into two flawed camps:

Per-expert LoRA (e.g., PERFT, DAS-LoRA): Attaches adapters directly to individual base experts. This adapts experts in isolation, ignores cross-layer dynamics, and fails if inference routes tokens to unadapted experts.

Standard MoE-LoRA (e.g., MoELoRA, MoLA): Adds a separate pool of LoRA experts with its own independent router trained from scratch. This throws away the rich specialization signals already encoded in the pretrained MoE router.

Key Results
Evaluated across MoE backbones of varying scales and granularities (including OLMoE-1B-7B, DeepSeek-V2-Lite, Qwen3-30B-A3B, and multimodal Qwen3.5-35B-A3B), 
MoE
